预期: 上限 +0.5-1% (Q8_0 占权重 13% / 2.85GB, 是 A1 唯一没覆盖的量化类型)

## 任务

1. 测量 Q8_0 反量化吞吐 (dequant_bench / 微基准), 与 Q6_K/Q5_K 的 707-825 GB/s 参考线对比;
   用 nsys 确认它在 pp512 里的时间占比
2. 若 Q8_0 路径明显偏慢 (< ~700 GB/s) 且向量化后能省 **>=2ms/ubatch (>=+0.4% pp512)**:
   按 A1 同法向量化 (运算与舍入保持逐位相同), patch 归档
3. 否则: 记录数字, 关闭 (不投入)

## 验收 (仅当实施)

- PPL 门槛 (期望逐位相同) + pp512/4096/8192; 32K 口径各 1 次 (pp32768/depth32k)
- **pp8192@depth128k 不回退 (长文代表点, 用户 Q14 指定)**
- 端到端同 session A/B 交替 >=2 轮
- 成本: 测量 0.5h; 实施 0.5-1h
