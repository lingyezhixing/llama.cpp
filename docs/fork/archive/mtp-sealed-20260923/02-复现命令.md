## 调用方式

- 最简单：浏览器打开 `http://127.0.0.1:8080`，用内置聊天页（`--jinja` 会用模型自带模板）
- API（脚本口径，注意 body 用 UTF-8 字节发，否则中文问题会被编码坏）：

```powershell
$body = @{
  messages = @(@{ role = "user"; content = "你的问题" })
  temperature = 1.0; top_p = 0.95; top_k = 20; min_p = 0.0; seed = 42
  max_tokens = 131072; stream = $false
} | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri "http://127.0.0.1:8080/v1/chat/completions" -Method Post `
  -Body ([System.Text.Encoding]::UTF8.GetBytes($body)) -ContentType "application/json"
```

响应里 `choices[0].message.content` = 最终回答，`choices[0].message.reasoning_content` = thinking（自动分离，弃用即可）。

## 注意

- 贪婪（`--temp 0 --top-k 1`）跑这种放宽的创作题会复读狂奔（实测 10 分钟不结束），所以实际口径用 `--temp 1.0`
- 想收住输出可加 `-n 8192`，但那是另一套口径
- 修复版的两个环境变量必须设，否则等于 T19（未修复）
