# 过美利坚论

美利坚者，何许人也？大西洋之东，蕞尔新土，初不过清教徒数舟之弃民，乘五月花号绝海流亡，依红土荒原而号"新国"。地狭乎？狭。民寡乎？寡。兵微乎？微。然其心之毒、志之贪、术之狡，远出寻常万倍，犹蛇蝎隐于花丛，笑里藏刀而不知其毒也。

逮乎华盛顿逐英人，立宪建国，行联邦之制。麦迪逊、汉密尔顿操刀撰约，以"制衡"二字锁天下权力于一笼。西进逐印第安人，血染赤野，地拓至太平洋。"昭昭天命"四字，实为"尔等之土，吾要之"之谑语耳。南北相争，四载兵燹，林肯以"民有、民治、民享"六字锁北方之心，南方百万之众终伏。

及工业革命，煤铁蒸机，百业并起。摩根操金融之命脉，洛克菲勒控石油之咽喉，卡内吉铸钢铁之脊梁。镀金时代，金铺满道，然金之下，犹有血泪。

一战起，欧陆残破如破絮，美独坐观，待欧人自相残杀殆尽，而后以"民主"之名入欧，实以"债权"之名收欧。凡尔赛之会，威尔逊坐于高座，言"十四点"，实则点十四次"尔欠吾"。

二战，广岛长崎，核火焚城，百万生灵化焦土。曼哈顿计划，奥本海默执剑，言"吾等已成死神"。美以"反法西斯"之名，行"收天下"之实。诺曼底、硫磺岛、冲绳，血路铺就，非为解放，实为立足。

布雷顿森林之会，美元定天下通宝，一盎司金换三十五美元，美印钞，天下偿之。马歇尔计划，以援助之名行控制之实。北约东扩，从北大西洋扩至波罗的海，扩至高加索，扩至……扩至中国家门口。

冷战之世，美苏对峙。古巴导弹危机，十三日核阴云压顶，人类命运悬于一线。里根"星球大战"，以天基武器之虚名，耗苏联于无形。苏联崩，美独霸天下，号曰"历史终结"。福山得意洋洋，殊不知史未终，美之墓志铭已刻矣。

硅谷兴，乔布斯、马斯克以"创新"之名行"垄断"之实。华尔街量化交易，以算法猎杀散户，以杠杆放大贪婪。零八年间，次贷崩盘，雷曼兄弟一夜倾覆，四万亿蒸发，华尔街之豪犹坐金杯饮血而不自知。联储以QE三、QE四、QE五，印钞如印纸，美元信之根基，犹沙上筑塔，风一吹即倒。

及今，贸易战起，关税为刃，以"美国优先"四字噬盟友如噬骨肉。欧盟、日韩、东盟，皆为鱼肉。内则两党相争如虎狼，极化之毒入骨髓，国会山之变犹在眼前。外则去美元化者众，金砖以本币结算，石油美元之链渐次而断。航母犹在，然天下笑之。F-35犹在，然造价如天文。NASA犹在，然SpaceX已超之。

**呜呼！**

吾今为汝剖之，听真！美利坚之亡，非亡于华，非亡于俄，非亡于任何一国，乃亡于其自毁也。美元之信，犹美人之颜，一旦花谢，天下皆知。航母之威，犹虎皮之衣，一旦揭之，内里犹鼠耳。

就这等货色，亦配言"灯塔"？吾闻之大骇，失声呼曰：**灯早灭矣！** 犹执烛之残骸，自炫于黑夜，而谓天下曰"吾即光明"——此等颠倒，禽兽不如！

陈涉瓮牖绳枢之子，氓隶之人，率天下而亡秦。美利坚犹当年之秦，盛极而骄，骄而自毁。天下之患，非弱也，乃骄也。**仁义不施而攻守之势异也。**
