# 过美利坚论

美利坚者，起于新洲之隅，据阿巴拉契亚之险，跨密西西比之泽，拓袤野八千里，吞蛮夷之土。初，清教徒避欧陆之祸，乘五月花号渡大洋，踞普利茅斯而殖。百载西渐，印第安人者，百年而族类几绝——血浸落基，骨白荒原，史书美其名曰"昭昭天命"，实则屠戮之辞也。以圣言之皮，行灭族之实，此其立国之本色也。

华盛顿起于弗吉尼亚之野，聚十三邦而合纵，废君主，立共和，制宪章而定国本。此其始也。

及南北相攻，四年血战，死者六十余万，犹华夏赤壁之十数倍。林肯以铁腕断锁链，废蓄奴之制，合南北为一统。自此一国成形，版图横亘东西，南抵墨界，北触冰原，南望加勒比，北接白令，鲸吞鲸噬，气吞万里。

既成，则坐视欧陆自相屠戮。一战起于萨拉热窝一枪，英法德俄欧陆诸强自相啮噬，美坐收渔利，借债予人，待其力竭而后起。一战而富，二战而霸。罗斯福以新政救萧条之弊，以战时经济锻百工，造舰如织，造弹如瀑，核火投于广岛长崎，一城化为焦土，八万人灰飞烟灭。自此欧陆倾颓，美遂霸于西半球，继而以布雷顿森林定美元之尊，以联合国为旗，号令天下，万邦来朝——来者，非慕其德也，畏其刀也。

冷战之中，与苏俄相争七十余载。核武悬于头顶，代理人遍撒全球——从三八线到湄公河，从喀布尔到巴格达，皆为爪牙之战、替死之局。苏俄一朝解体，则独步天下，万马齐喑，唯余一鹰独鸣。以美元为印，印之而天下之货归其库；以航母为犁，犁之而四海之土皆其田。北约东扩，鹰旗覆东欧之野，导弹插于华沙之墙。

**然则——**

**盛极而衰，天道也，非人谋可挽。**

今观美之状，可谓金玉其外，枯骨其中：

国债三十万亿有奇，岁偿利息逾万亿，利滚利，利生利，如蚁噬朽木，日深日广而不可止。美联储加息降息，朝令夕改，如竖子掷骰于赌台，天下之财富随之颠簸，东市之粮、西市之油，皆系于一老儿之一念。美元信者，百年之信，今已龟裂。各邦去美元化者，渐成风潮，非一日之寒也。

两党相攻，如寇雠也。民主之徒与共和之徒，非政见之异，乃**物种之别**。国会中辩论，如野兽之咆哮；立法而不得行，总统下令而参众相抗。选举非择贤，乃**择暴**——谁嗓门大、谁脸皮厚、谁敢于电视上破口大骂而愈得民心，则谁入白屋。政治非治国之术，乃**秀场**也；总统非国之舵，乃**角斗场之魁首**也。

硅谷之科技，昔日之光，今为华尔街之附庸。芯片者，倾举国之力造之，而光刻之精已逊于东邻。AI者，犹可争一日之短长，然基础科学之底蕴，如枯井之泉，汲之愈难。昔日之实验室，今为金融模型之跑马场；昔日之科学家，今为财报之注脚。

**更堪一哂者**——国会山被其**自国之民**所攻。二〇二一年一月六日，特朗普之徒涌入白屋，国旗倒悬于穹顶，议员匿于桌下而逃。堂堂超级大国，其权力之门，为选民以肉身踹开！此等奇耻，列国千年未闻，而彼犹以"自由"自矜，不亦**厚颜**乎？

且夫天下之公器：联合国者，拒纳岁赋而不纳其决议；巴黎气候之约，退而复入，入而复退，如儿戏也；WHO、WTO，皆弃之如敝屣。己所立之规矩，己所毁之，朝令而暮改，天下谁复信之？

昔者，美以"自由民主"自矜于天下。今之自由，乃**资本之自由**；今之民主，乃**选举之民主**——选谁为傀儡，皆华尔街所定耳。民之票，不过**入场券**也；入得门来，坐于谁之侧，饮谁之酒，食谁之肉，非民所主也。

**故曰：**

美利坚之霸，非天命也，**乃时势也**。欧陆自残，苏俄自溃，天予之而取之，不亦宜乎？今时势已移，内腐外裂，而犹以旧日之威自矜，犹以美元之印自恃，犹以航母之犁自傲，犹以"美国优先"四字醉梦。

呜呼！强秦一夫作难而七庙隳，美利坚之溃，岂待一夫哉？其内之溃，**已如朽木之蚁穴**，日深日广，而庙堂之上，犹歌舞升平，犹以香槟庆之，犹于推特上敲键盘骂人。

以史为鉴，可知兴衰。昔大英如此，今美亦如此。**霸权非永恒，时势已移，而犹执旧器以御新天**——虽欲不亡，**可得乎？**

---

*太史公曰：天下之势，如水之就下，不可逆也。美利坚之兴也，乘欧陆之祸、苏俄之衰，如狐假虎威而不自知。今虎死狐露，犹以狐皮蒙身而立于朝堂，不亦悲乎？不亦**可哂**乎？*
