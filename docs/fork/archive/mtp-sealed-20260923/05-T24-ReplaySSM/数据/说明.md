# 数据说明

均为贪心、确定性、可逐字节比对；模型 `Qwen3.8-27B-UD-Q6_K.gguf`，`-ngl 99 -fa on -ctv q8_0`，seed 42。

## d0_*.txt —— 长跑对照（1000 token）

口径：`-c 4096`，请求 `prompt="Write a long detailed essay about the history of computing. Be verbose."`，
`n_predict=1000, cache_prompt=false, temperature=0, top_k=1, min_p=0, seed=42, return_tokens=true`。

| 文件 | 说明 |
|---|---|
| `d0_base.txt` | 不开 spec |
| `d0_old-mtp.txt` | `--spec-type draft-mtp --spec-draft-n-max 3`，老快照路径 |
| `d0_replay-mtp.txt` | 同上 + `GGML_CUDA_GDN_REPLAY=1` |

结论：**老 vs replay 逐 token 完全相同**；两者与 base 都在 token 38 分叉
（选核轴，与 T24 无关）。

## mtp3_64_*.txt —— 短跑三臂（64 token）

口径：`-c 16384`，prompt `"The quick brown fox jumps over the lazy dog. Count from 1 to 40 slowly."`，
`n_predict=64, temperature=0, seed=42, ignore_eos=true, return_tokens=true, cache_prompt=false`。

| 文件 | 说明 |
|---|---|
| `mtp3_64_base.txt` | 不开 spec |
| `mtp3_64_old-mtp.txt` | 老快照路径 |
| `mtp3_64_replay-mtp.txt` | replay 路径 |
| `mtp3_64_replay-check.txt` | replay + `GGML_CUDA_GDN_REPLAY_CHECK=1` 自检运行 |

结论：三臂 **64/64 完全一致**；自检运行无 `fold did not reproduce` 报错。
